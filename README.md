# 轻舟 · Windows 工作台

把常用应用、AI对话和办公文件放在一个工作台。

[下载最新版](https://github.com/991206772-debug/qingzhou-releases/releases/latest)

![小舟伙伴](brand-companion.png)

下载Release中的Qingzhou-Setup安装包，安装后从桌面“轻舟”打开。首次使用请配置自己的模型服务。Windows 10/11 64位。

新版支持在“设置 → 关于与更新”中检查、下载和重启更新，沿用首次安装目录并保留个人配置和聊天记录。生成文件期间不会自动重启。

本仓库只提供安装包、更新说明和反馈入口。源码保存在独立私有仓库，不包含在本仓库。

反馈问题时可从“会话详情”复制会话ID并导出诊断。诊断含该段对话文字，请确认内容适合公开后再附到Issue；不要上传模型密钥。
